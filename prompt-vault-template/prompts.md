# Prompt Vault Database

This file is the single source of truth for all stored prompts. Each prompt is
a level-2 section (`## `) so entries can be located and edited reliably with
exact-string replacements. Do not reformat or "clean up" existing entries —
only add, edit, or remove the specific entry requested.

Checkbox legend: `[ ]` = pending, `[x]` = completed.

Valid categories: Claude Code, ChatGPT, Coding Projects, Research, Other.

Fence rule: each prompt sits in a fence of N backticks (N = longest backtick
run inside the prompt + 1, minimum 3), closed by a line of at least N backticks.
